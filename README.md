# CNN_prj

CNN learning projects and reference materials.

- AlexNet, GoogLeNet, LeNet, ResNet, VGG16: image classification experiments.
- fight-detection, video-recognition: video classification experiments.
- yolov3: object detection code, configuration files and sample images.
- Additional folders contain course materials, papers and source documentation.

Training datasets, model weights, generated results, local environments and large
ZIP archives are excluded from Git. Keep or download them locally before training;
check each training script for the expected data and weight paths.

The local `yolov3` folder retains its independent Git repository. This repository
tracks a snapshot of its source files directly, so a clone includes the source
without requiring a submodule checkout.
